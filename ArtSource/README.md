# ArtSource (not in git)

Blender sources (`.blend`) and other working files live here, or anywhere outside the repo. Git ignores
everything in this folder except this README (decision D-0004: exports in git, sources outside, no LFS).

**Back this folder up separately** (for example, a cloud-synced copy). Git does not protect it.

## Pipeline

1. Model in Blender and save the `.blend` here.
2. Export FBX into `Assets/Art/<Category>/`; Unity imports it on the next focus or batch run. Reuse the export
   settings that worked in InsignificAnts and Sol's Box, and note them here once settled.
3. Icons and UI images: PNG into `Assets/Art/Icons/` (transparent background).
4. Tell Claude the asset path. Claude wires it in code: scenes are generated by `MainSceneBuilder`, so art is
   referenced from code, not placed by hand in the scene.

Until Norm's assets arrive, Claude uses Unity primitives as placeholders.
