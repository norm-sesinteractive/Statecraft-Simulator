# D-0002: Mobile first: Android, then iOS, PC later

**Status:** Accepted (Norm, 2026-10-14) | **Date:** 2026-10-14 | **Area:** Platform

## Context
Claude asked which platform comes first; Claude had suggested PC first.

## Decision
Norm chose mobile first, like InsignificAnts: Android, then iOS, PC later.

## Because
Norm's call. Consequences: touch-first UI, sizes relative to the 1080 px reference height, ASCII-only UI text,
safe-area padding, the app pauses when sent to the background, Android player settings from day one (D-0017),
and device checks for anything that can differ on hardware.
